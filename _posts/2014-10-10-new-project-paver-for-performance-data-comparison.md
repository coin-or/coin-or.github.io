[Paver](https://projects.coin-or.org/Paver) is a collection of Python scripts meant to simplify the task of performance data comparison and visualization. Some example usages of PAVER can be found [here](http://www.gamsworld.org/performance/paver2). This [paper](http://www.gamsworld.org/performance/paver2/paver2_paper.pdf) describes the setup, usage, and features of Paver.
