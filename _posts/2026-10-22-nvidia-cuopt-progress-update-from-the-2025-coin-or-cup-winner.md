NVIDIA cuOpt, winner of 2025 COIN-OR Cup, version 26.10 is now officially released and available via GitHub [repo](https://github.com/NVIDIA/cuopt), Docker Hub [page](https://hub.docker.com/r/nvidia/cuopt/tags), and is also installable via pip and conda.For cuOpt documentation including release notes for 26.10, please visit [here](https://docs.nvidia.com/cuopt/user-guide/latest/introduction.html).

cuOpt™ is a GPU-accelerated optimization engine that targets linear programming (LP), quadratic programming (QP), and vehicle routing problems (VRP), with support for quadratically constrained quadratic programming (QCQP) (beta), second-order cone programming (SOCP) (beta), and mixed integer programming (MIP) (beta). cuOpt enables near real-time solutions for large-scale LPs with millions of variables and constraints and offers easy integration into existing modeling languages and deployment across hybrid and multi-cloud environments.

For any questions or need for support, please visit cuOpt repo [Discussions](https://github.com/NVIDIA/cuopt/discussions) page.
