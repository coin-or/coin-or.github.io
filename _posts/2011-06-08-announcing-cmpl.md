title: "Announcing CMPL"
date: 2011-06-08 09:00:00
author: Andrew Mason
---

Mike Steglich and Thomas Schleiff announced CMPL. CMPL is a mathematical programming language and a system for modelling, solving and analyzing linear programming (LP) problems and mixed integer programming (MIP) problems. The CMPL syntax is similar in formulation to the original mathematical model but also includes syntactic elements from modern programming languages. CMPL uses the COIN-OR [OSSolverService](https://projects.coin-or.org/OS "OS: Optimization Services") to solve LP and MIP problems. For more information, please visit the [CMPL project page](https://projects.coin-or.org/Cmpl/ "CMPL: Coliop / Coin Mathematical Programming Language").
