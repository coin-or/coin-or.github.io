## Andrew Mason and Iain Dunning

### OpenSolver

The submission "OpenSolver: Open Source Optimisation for Excel using COIN-OR", by Andrew Mason and Iain Dunning, has been selected as the winner of the 2011 edition of the [COIN-OR INFORMS Cup](/coincup/). [OpenSolver](http://opensolver.org) is an "Open Source linear and integer optimizer for Microsoft Excel. OpenSolver is an Excel VBA add-in that extends Excel's built-in Solver with a more powerful Linear Programming solver."
