Management for all COIN-OR projects is now officially under the auspices of the [COIN-OR organization at Github.](https://github.com/coin-or) You can find detailed instruction on obtaining, configuring, compiling, installing, and finally using the COIN-OR libraries (primarily the projects in the [COIN-OR Optimization Suite](https://github.com/coin-or/COIN-OR-OptimizationSuite)) at the [COIN-OR User’s Guide](/docs/user_introduction.html) or by visiting the Github pages of individual projects.

We have collected our most popular optimization projects together to form the *[COIN-OR Optimization Suite](https://github.com/coin-or/COIN-OR-OptimizationSuite).* Projects currently included in the COIN-OR Optimization Suite are listed below (with links to the GitHub pages for each one).

  - [CoinUtils](https://github.com/coin-or/CoinUtils) (COIN Utilities)
  - [Osi](https://github.com/coin-or/Osi) (Open Solver Interface)with interfaces to
      - [Clp](https://github.com/coin-or/Clp)
      - [Cbc ](https://github.com/coin-or/Cbc)
      - [SYMPHONY](https://github.com/coin-or/SYMPHONY)[ ](https://github.com/coin-or/Symphony)
      - [Vol](https://github.com/coin-or/Vol) [ ](https://github.com/coin-or/Vol)
  - [Clp](https://github.com/coin-or/Clp) (COIN LP Solver)
  - [DyLP](https://github.com/coin-or/DyLP)
  - [FlopC++](https://github.com/coin-or/FlopCpp)
  - [Vol](https://github.com/coin-or/Vol) (Volume Algorithm)
  - [Cgl](https://github.com/coin-or/Cgl) (Cut Generation Library)
  - [Cbc](https://github.com/coin-or/Cbc) (COIN Branch and Cut)
  - [SYMPHONY](https://github.com/coin-or/SYMPHONY) (MILP Solver Framework)
  - [Smi](https://github.com/coin-or/Smi) (Stochastic Modeling Interface)
  - [CoinMP](https://github.com/coin-or/CoinMP)

  - CHiPPS (COIN High Performance Parallel Search Framework: [Alps](https://github.com/coin-or/CHiPPS-ALPS)/[BiCePS](https://github.com/coin-or/CHiPPS-BiCePS)/[Blis](https://github.com/coin-or/CHiPPS-BLIS))

### Docker Images

Docker images for some COIN-OR projects (as well as the entire Optimization Suite listed above) are available at [COIN-OR’s DockerHub organization](https://hub.docker.com/orgs/coinor/repositories).

### Source Code Management

Source code management for all COIN-OR projects is now officially under the auspices of the [COIN-OR organization at Github.](https://github.com/coin-or) As noted above, you can find detailed instruction on obtaining, configuring, compiling, installing, and finally using the COIN-OR libraries (primarily the projects in the COIN-OR Optimization Suite) at the [COIN-OR User’s Guide](/docs/user_introduction.html) or by visiting the Github pages of individual projects.

Archives containing the source code for the latest releases of each project can be obtained by visiting the releases page for each project (see [here](https://github.com/coin-or/) for a list of project web pages).

### On-line Services

[NEOS](http://www.neos-server.org/)  
Some COIN-OR solvers can be accessed on-line through NEOS. You only need a description of the optimization problem you want to solve — all additional information required by the solver is determined automatically. The following COIN-OR solvers run on NEOS. (Click on the links below to get to the solver’s webpage on NEOS.)

  - [BonMin](http://www.neos-server.org/neos/solvers/minco:Bonmin/AMPL.html), Basic Open-source Nonlinear Mixed INteger program solver on NEOS using AMPL input.
  - [CLP](http://www.neos-server.org/neos/solvers/lp:Clp/MPS.html) COIN Linear Program Solver on NEOS using MPS input
  - CBC Coin Branch and Cut Solver on NEOS
      - [using MPS input](http://www.neos-server.org/neos/solvers/milp:Cbc/MPS.html)
      - [using AMPL input](http://www.neos-server.org/neos/solvers/milp:Cbc/AMPL.html)
  - [IPOPT](http://www.neos-server.org/neos/solvers/nco:Ipopt/AMPL.html) Large-Scale Nonlinear Optimization Solver on NEOS using AMPL input
