This page presents outside resources related to COIN-OR. Information on COIN-OR projects themselves may be found through the [Projects](/projects/) page or the [Documentation](/documentation.html) page.

Suggestions for links to include on this page may be emailed to *editor at coin-or.org*.

### Other Open-Source Tools for OR

  - [Cliquer](http://users.tkk.fi/~pat/cliquer.html): for finding cliques in graphs
  - [Gnumeric](http://www.gnome.org/projects/gnumeric/): spreadsheet with solvers
  - [GNU Scientific Library](http://www.gnu.org/software/gsl/): C library for mathematical functions, including random variables, statistics, linear algebra, and lots more.
  - [GOBLIN](http://www.math.uni-augsburg.de/opt/goblin.html): graph optimization library
  - [Maxima](http://maxima.sourceforge.net/): computer algebra, similar to Mathematica or Maple.
  - [MCFClass](http://www.di.unipi.it/optimize/Software/MCF.html): interface for Minimum Cost Flow problems (mix of open-source and other software)
  - [mexclp](http://control.ee.ethz.ch/~joloef/clp.php): a MATLAB interface to [CLP](/projects/index.html#CLP)
  - [MINLP](http://www.minlp.org/): CMU-IBM Cyber-Infrastructure for MINLP
  - [MUMPS](http://graal.ens-lyon.fr/MUMPS/): a MUltifrontal Massively Parallel sparse direct Solver
  - [Octave](http://www.octave.org/): matrix based mathematics, similar to and “mostly compatible” with MATLAB.
  - [OpenForecast](http://openforecast.sourceforge.net/): the name says it all
  - [QtsPlus4Calc](http://qtsplus4calc.sourceforge.net/): a collection of OpenOffice spreadsheets that solve a variety of problems related to queueing theory.
  - [R](http://www.r-project.org/): statistics, graphics, and more. Similar to S-plus (both are based on the language S).
  - [Shogun](http://www.shogun-toolbox.org/): a large-scale machine learning toolbox.
  - [swIMP](http://swimp.sourceforge.net/): SWIG-based interfaces for Mathematical Programming
  - [Zimpl](http://www.zib.de/koch/zimpl/): translate LP/MIP models into MPS or LP formats

### Tools Used by COIN-OR

  - Version control tools: [Subversion](http://subversion.tigris.org/), [TortoiseSVN](http://tortoisesvn.tigris.org/), [git](https://git-scm.com/)
  - [Trac](http://www.edgewall.com/trac/): project management (currently only used for new projects)
  - [Make](http://www.gnu.org/software/make/): used by many projects to control the compilation and linking process
  - [GNU Autotools](https://www.gnu.org/software/autoconf/autoconf.html)
  - [Doxygen](http://www.doxygen.org/): used by many projects to generate documentation from C++ header files
